# دفتر ساختمان

سامانهٔ فارسی برای مدیریت و حسابداری ساخت ساختمان، به‌اضافهٔ حساب‌های شرکت و حساب‌های شخصی صاحب‌کار.
ورودی اصلی ویس و عکس رسید و فاکتور است (از ربات بله و تلگرام یا همین سایت). سیستم آن‌ها را می‌فهمد و کارت پیشنهادی می‌سازد،
و تا صاحب‌کار تأیید نکند چیزی ثبت نمی‌شود. همهٔ ویس‌ها و عکس‌ها برای همیشه بایگانی می‌شوند.

طرح کامل: [docs/plan.md](docs/plan.md)

## وضعیت

فاز ۱، بخش بدون سرور:
- ساختار دیتابیس Supabase با دسترسی نقش‌ها، تاریخچهٔ غیرقابل‌تغییر و بایگانی (`supabase/migrations`)
- قالب ۲۵ مرحلهٔ ساخت با گام‌ها، نقاط کنترل ناظر و مدارک لازم هر مرحله
- داشبورد شیشه‌ای در Next.js، فعلاً با دادهٔ نمونه

هنوز نیست: ورود با پیامک، ربات‌ها، سرور واسط هوش مصنوعی، پشتیبان‌گیری.

## اجرا

```bash
npm install
npm run dev
```

## تست

```bash
npx vitest run
```

تست‌های دیتابیس migrationها را در Postgres درون‌حافظه‌ای (PGlite) اجرا می‌کنند.
